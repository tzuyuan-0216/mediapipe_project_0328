# 🎮 MediaPipe 互動式風格遊戲

這是一個基於 **Vue 3** 與 **Vite** 開發的實驗性前端專案。本專案利用 **MediaPipe Hands** 實現了完全去滑鼠化的「無接觸手勢操作」體驗。

---

## 核心互動體驗

本系統目前整合了核心頁面，並針對不同的情境採用不同的 AI 視覺模型優化：

### 1. 智慧去滑鼠化導覽控制 (首頁主選單)
* **無接觸手勢控制**：透過偵測右手腕與食指尖的相對距離（Pinch 捏合手勢），實現完全隔空模擬實體滑鼠的「點擊」與「釋放」動作，控制 UI 橫向捲動選單與頁面進入。
* **雙層虛擬游標與響應式補間 (Lerp)**：畫面採用藍白雙層虛擬游標，底層透過數學內插法實作防手震與滑順跟隨，並完美解決虛擬游標與原生 CSS `:hover` 脫鉤的問題，提供 100% 準確的 UI 懸停放大反饋。

### 2. AI 智能照相館 (Hands 手部感應)
* **全螢幕沉浸取景**：鏡頭畫面自動適應瀏覽器大小，提供無邊框的互動拍貼體驗。
* **張掌計時自動拍照**：感應到使用者「張開手掌」持續 2 秒，即可觸發 3 秒倒數計時並自動拍照，完全不需碰觸任何硬體設備。
* **即時垂直預覽清單**：拍完的照片會立即生成縮圖，並顯示在左側側邊欄，方便使用者即時檢視互動成果。

### 3. 互動式靜思語 (Pose 肢體感應)
* **靜心彎腰感應 (頂禮觸發)**：利用 Pose 模型即時計算肩膀與髖關節的距離，精準偵測使用者「合掌向前彎腰頂禮」的動作。當滿足特定的深蹲或彎腰角度時，瞬間觸發抽選。
* **影音流暢串接**：動態隨機抽取 305 部本地端靜思語動畫短片，達到無網路延遲、零廣告干擾的沉浸式體驗。
* **展場音效反饋**：影片播放完畢後，自動觸發清脆的「銅鑼聲」音效，深化展場的禪意氛圍。

## 🚀 快速啟動

### 1. 環境準備
確保你的電腦已安裝 [Node.js](https://nodejs.org/)。

### 2. 專案設定與安裝
```sh
# 安裝依賴
npm install

# 本地開發 (Hot-Reload)
npm run dev

# 專案打包 (Production)
npm run build

# 程式碼檢查 (Lint)
npm run lint
